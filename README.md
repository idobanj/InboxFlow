# InboxFlow - Landing Page

A modern, responsive landing page for InboxFlow, a SaaS platform that helps professionals supercharge their workflow by delivering curated insights directly to their inbox.

## 🚀 Overview

InboxFlow features a clean, minimalist design focused on user engagement through strategically placed call-to-action forms and compelling feature highlights. The page demonstrates modern web development practices with full support for all CSS color formats.

## ✨ Key Features

- **Hero Section**: Eye-catching headline with email signup form
- **Features Showcase**: Three key benefits - Speed, Security, and Quality
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile
- **Form Handling**: Interactive forms with validation
- **Multi-Color Format Support**: Demonstrates Hex, RGB, RGBA, HSL, HSLA, and named colors
- **Custom SVG Graphics**: Abstract hero image with gradient effects

## 🛠️ Technologies

- HTML5, Tailwind CSS, Vanilla JavaScript, Custom CSS, SVG

## 🚦 Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
This runs Tailwind CSS in watch mode, automatically rebuilding CSS on file changes.

### Build
```bash
npm run build:css
```
